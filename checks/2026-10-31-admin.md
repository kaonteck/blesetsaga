## 백엔드 요청
1. **[5단계 전 필수] 유저끼리 우편으로 골드·아이템을 만들어 낼 수 있음.** `mail` INSERT 권한에 `items`·`gold`가 들어 있고, 정책은 보내는 사람·받는 사람만 확인. 보내는 쪽에서 차감하지 않으므로 아무 계정이나 다른 계정에 `gold=999999`를 보낼 수 있음(`claim_mail`이 그대로 지급). 지금은 게임이 아직 이 표를 쓰지 않아 실제 위험은 없지만, 08-server.js 연결 전에 막아야 함. 방법: 유저 INSERT 정책에 `items='{}'::jsonb and gold=0` 추가, 선물은 차감까지 하는 서버 함수로.
   - 참고: 실제 DB에는 계정이 1개뿐이라 이 항목은 SQL을 읽고 판단함(받을 사람이 없어 실행 시험은 못 함).
2. **[낮음]** Supabase 보안 점검: 유출 비밀번호 차단(Leaked Password Protection) 꺼져 있음 → Auth 설정에서 켜기.
3. 참고(조치 불필요): 보안 점검의 "로그인 사용자가 SECURITY DEFINER 함수 실행 가능" 경고 12건은 의도된 것. 모두 함수 안에서 운영자·본인 확인을 함.
